Foxtel

Streaming service workflows

Foxtel uses Conductor to coordinate backend workflows across Binge and Kayo, connecting distributed application services through a shared orchestration platform.

Data Lifecycle Management

Foxtel

Expired content license cleanup

Conductor coordinates cleanup workflows for expired content licenses across distributed services. The implementation evolved toward Orkes while retaining workflow orchestration for content lifecycle operations.

Document and Content Processing

Kayo Sports

Live event replay processing

Conductor coordinates Live2VOD workflows that harvest video from live-stream endpoints, transform the assets and make them available as replays after the event.

Process Automation

Kayo Sports

Reusable integration workers

Conductor workflows use configurable workers for email, HTTP requests, workflow logic and AWS services, providing reusable building blocks for the application’s asynchronous processes.

Process Automation

Hybrid service workflows
