Infrastructure Lifecycle

Product implementation and configuration

Amadeus’ Maestro engine is built on Conductor to automate product implementation, configuration and deployment. Workflows manage travel-agency offices, users and product settings, adapting each implementation to the requirements of its market and customer. Teams define and monitor workflows through the Amadeus Configuration Platform, with workers connecting the systems and services involved.

Data Pipelines and Analytics

Revenue accounting batch processing

A Conductor-based batch framework coordinates critical data flows within airline revenue accounting. Recoverable workflow execution manages dependent processing stages and provides a shared structure for running accounting data jobs.

Software Delivery

Reusable workers and workflow tracing

Conductor worker libraries and distributed tracing support Amadeus workflow applications. A Go worker SDK simplifies service integration, while OpenTelemetry and Tempo make execution paths visible in the Maestro orchestration platform.

Software Delivery

Shared action orchestration

Amadeus engineers built a shared action orchestrator with Conductor, connecting reusable actions and low-code workflow creation within a common execution framework.
