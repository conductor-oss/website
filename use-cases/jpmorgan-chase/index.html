Security Operations

Cybersecurity investigation workflows

Conductor supports threat-analysis orchestration for phishing, malware investigations and digital forensics, connecting investigation services within the bank’s cybersecurity automation environment.

Process Automation

Production management automation

Conductor supports production-management automation for incident, change and problem-management tasks. Within Consumer Banking infrastructure, related business-rules and recovery workflows coordinate operational work and reduce the manual effort needed to restore services.

Security Operations

Identity and access workflows

Conductor coordinates identity workflows that connect risk scoring, account provisioning and related services. The workflows carry state across the steps needed to create and manage access within banking applications.

Software Delivery

Microservice workflow testing

JPMorgan Chase used Conductor in automation testing of workflows that span microservices. The engineering work used orchestrated workflows to process and analyze testing across distributed application components.
