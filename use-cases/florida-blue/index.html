Case Management

Customer service requests

Conductor supports Customer Connect service requests, work queues and work-management processes, coordinating service activity across the customer-care application.

Process Automation

Employer group renewals

Conductor supports renewal processing for large employer health-insurance groups, coordinating the application workflows that move renewal cases forward.

Case Management

Claims workflows

Conductor supports claims workflows in a web application developed to modernize a legacy desktop process.

Risk and Compliance

Compliance case progression

Conductor coordinates insurance compliance cases, including progression through service stages, deadlines and communication among participants.

Data Pipelines and Analytics

Near real time data processing

Florida Blue used Conductor to replace daily ETL jobs with near-real-time processing. The workflows connected data-processing stages so that information could move through the application more frequently than the previous batch cycle.

Process Automation

Precision health management workflows

Conductor supports Florida Blue’s Care Connect Precision Health Management workflows, connecting incoming triggers with service-task processing. The application combines data from external sources with the core care-processing system, with workflow behavior validated through API and task-processing tests.

Software Delivery

Application workflow validation

Conductor is used to run application workflows during Florida Blue’s quality-assurance testing. Engineers submit workflows with Postman and check application behavior through backend, frontend and end-to-end tests.

Process Automation

Agency workflow applications

Florida Blue engineers built Conductor workflows with a React interface for an Agency Resource Center. The application connects workflow execution with insurance agency, agent and policy information.
