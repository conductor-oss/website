Imaging AI integration

Related tooling includes a visual editor for decisions, parallel branches and service calls, with versioning and status listeners supporting workflow operation.

AI and Machine Learning

Breast imaging AI

Conductor orchestrates imaging AI workflows for MyBreastAI, coordinating algorithm execution within a container-based deployment environment.

Process Automation

CT protocol and processing workflows

Conductor coordinates dependent services for cloud-hosted CT protocol management and supports workflow execution in CT post-processing applications.

Data Pipelines and Analytics

Cardiac CT processing at the edge

GE HealthCare’s SnapShot Freeze 2 application integrates Conductor as a supporting service in its cardiac CT processing environment. The application runs a motion-artifact-reduction algorithm as a Kubernetes job on an edge device, with autoscaling, Helm packaging and recovery testing supporting its delivery.

Process Automation

Background imaging jobs

Conductor coordinates background medical-imaging jobs, DICOM networking and resource-based application execution. Queue visibility, retries, status tracking and parallel processing help imaging services manage work across available resources.

Network and Device Operations

Remote imaging application workflows

Conductor supports remote imaging application workflows, including Imaging360 editor orchestration and Digital Expert edge-gateway services. These applications connect remote access and device-side operations with the cloud services that coordinate the work.

AI and Machine Learning

CT software delivery across cloud and edge

GE HealthCare's Smart Subscription for CT uses Conductor within its cloud and edge orchestration stack. The platform coordinates work supporting AI-enabled capabilities in released medical imaging products.

Software Delivery

Reliability test architecture

Conductor forms part of GE HealthCare’s system reliability testing and test-architecture work. The engineering environment combines Conductor with container infrastructure, Spring Boot and Python for designing and developing test capabilities.

Software Delivery

Edison workflow validation

GE HealthCare tests its Conductor-based Edison AI Orchestrator across workflow creation, execution and monitoring. Verification covers the graphical interface and web services, with automated behavior-driven tests and validation before each release.

AI and Machine Learning

Clinical AI model development

Conductor forms part of GE HealthCare’s Edison AI Workbench technology stack. The workbench supports creating, testing and using AI models for clinical applications, with microservices handling imaging-data ingestion and model-development services across cloud and healthcare-device environments.
